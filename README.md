# Cassandra Trader

업비트 KRW 현물시장을 대상으로 하는 롱·현금 기반 알고리즘 자동매매 시스템입니다.

## 현재 단계

- Python 및 VS Code 개발환경 구축
- 프로젝트 패키지와 테스트 구조 생성
- 실거래 기능은 아직 구현하지 않음

## 기본 원칙

- 레버리지 및 공매도 사용 금지
- 완전히 종료된 4시간봉으로 정상 의사결정
- 위험 감시는 상시 수행
- 실거래 전 백테스트, 페이퍼 트레이딩, 소액 검증 실시
- API 키와 인증정보는 Git에 저장하지 않음

## 개발 명령어

```bash
uv sync
uv run ruff check .
uv run pytest
uv run cassandra-trader
```

## 주의사항

현재 버전은 개발 골격이며 실제 주문을 실행하지 않습니다.
